## Приложение Блог

Приложение написано с использованием фреймворка *Laravel*.

Приложение позволяет пользователю создавать посты и комментировать их.

Приложение включает элементы автомодерации. Запрещено упоминание любых ссылок в постах или коментариях.

Посты, не прошедшие автомодерацию, отправляются на ручную модерацию.

Посты, прошедшие модерацию, автоматически опубликуются в указанное время. Комментарии опубликуются сразу же, после прохождения автомодерации.

Любое изменение поста отправляет его на повторную модерацию.

Модерация выполняется параллельно работе приложения, используя Events и Listeners.

## Автоматическая публикация

Для автоматической публикации добавьте команду в crontab.

`* * * * * /path/to/php /path/to/project/artisan schedule:run >> /dev/null 2>&1`
